# Lucid Launcher Mobile — лёгкий «стеклянный» лаунчер

> 📱 **Это мобильная версия — для телефонов (Android).**
>
> Версию для планшетов и ТВ-приставок (с поддержкой D-pad) смотри в отдельном репозитории: [Lucid Launcher](https://github.com/dofiaaa/lucid-launcher).

Минималистичный лаунчер для телефона Samsung Galaxy A5 (Android 6.0, API 23). Максимально лёгкий: без AndroidX, без сторонних библиотек, чистый Android framework на Java.

## Возможности
- «Lucid glass» оформление: размытые обои + полупрозрачные стеклянные панели
- Крупные часы и дата
- Сетка приложений (4 колонки, алфавитная сортировка)
- Поиск по названию и имени пакета
- Нижний док: Телефон, Сообщения, Камера, Браузер (определяются автоматически)
- Длинное нажатие на иконку: открыть / о приложении / скрыть
- Скрытые приложения возвращаются через «шестерёнку» в углу
- Иконки грузятся в фоне, кэшируются в памяти
- Виджеты прямо в сетке приложений: добавление через системный пикер, настройка и удаление (долгое нажатие), автосохранение после перезапуска
- Переключатель «Стеклянные панели»: прозрачные ↔ непрозрачные (в меню «шестерёнки»)

## Сборка
Требуется JDK 17 и Android SDK (platform 34, build-tools 34.0.0).

### Android Studio
Откройте папку проекта, дождитесь синхронизации Gradle, затем **Build → Build APK(s)** — получится подписанный debug-APK, готовый к установке.

### Командная строка
```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_SDK_ROOT=/path/to/android-sdk
gradle :app:assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk` (уже подписан debug-ключом).

Для уменьшенного release-APK соберите `:app:assembleRelease` — он будет без подписи; подпишите его своим ключом или добавьте `signingConfig` в `app/build.gradle`.

## Установка
1. Скопируйте `app-debug.apk` на телефон.
2. В настройках разрешите установку из неизвестных источников.
3. Установите APK.
4. Нажмите «Домой» — система предложит выбрать лаунчер, выберите **Lucid Launcher Mobile** (и «Всегда»).

## Структура
- `LauncherActivity.java` — основной экран + хостинг виджетов (`AppWidgetHost`/`AppWidgetHostView`)
- `AppRepo.java` — загрузка списка приложений, док, кэш иконок
- `AppCell.java` / `LauncherGrid.java` — ячейка и грид-контейнер (иконки + виджеты вперемешку)
- `StackBlur.java` / `WallpaperBlur.java` — размытие обоев (CPU, без RenderScript)
- `Prefs.java` — сохранение скрытых приложений

## Настройка под себя
- Пакет и имя: `app/build.gradle` (`applicationId`, `versionName`) и `res/values/strings.xml`.
- Цвета стекла: `res/drawable/glass_pill.xml`, `glass_dock.xml` (непрозрачные версии — `panel_opaque.xml`, `dock_opaque.xml`).
- Количество колонок сетки: `LauncherGrid.COLUMNS`.
- Размер виджетов (в ячейках): `LauncherActivity.widgetSpanX()` / `widgetSpanY()`.

## Примечание про виджеты
Виджеты размещаются прямо в сетке приложений и занимают ячейки по своему размеру (ширина/высота из `minWidth`/`minHeight`). Добавление идёт через системный пикер `ACTION_APPWIDGET_PICK` — он сам привязывает виджет, поэтому отдельное разрешение не требуется. Виджеты со своей внутренней прокруткой (календарь-агенда, список задач) могут не прокручиваться внутри — это ограничение лёгкого лаунчера без вложенной прокрутки.
